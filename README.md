# MINI ARCADE – PLAY ZONE 🕹️

A collection of **10 fully playable arcade games** built with pure HTML, CSS, and JavaScript.

## 🎮 Games

| # | Game | Description |
|---|------|-------------|
| 1 | 🚀 Space Shooter | Shoot enemies and meteors from your spaceship |
| 2 | 🎯 Target Master | Click moving targets before they disappear |
| 3 | 🛸 Asteroid Dodge | Dodge asteroids from all directions |
| 4 | 🐍 Snake Mini | Classic snake — eat food, grow, don't crash |
| 5 | 🧠 Memory Match | Flip cards and find matching pairs |
| 6 | ⚡ Quick Reflex | Tap the target the moment it turns green |
| 7 | 🫧 Bubble Shooter | Match 3+ same-color bubbles to clear the board |
| 8 | 🧱 Brick Breaker | Break all bricks with the ball and paddle |
| 9 | 🐦 Flappy Style | Flap to stay airborne and pass through pipe gaps |
| 10 | 🏎️ Racing Mini | Race your car and dodge incoming traffic |

## 🌟 Features

- **10 unique playable games** with different mechanics
- **3 difficulty levels**: Easy, Medium, Hard
- **Lives system** with game over screens
- **Score tracking** with localStorage persistence
- **Leaderboard** showing top scores across all games
- **10 Achievements** to unlock
- **Virtual coins** earned from playing
- **Sound effects** (Web Audio API, toggleable)
- **Keyboard + touchscreen** controls
- **Fully responsive** — works on laptop and mobile

## 🕹️ Controls

| Game | Keyboard | Mobile |
|------|----------|--------|
| Space Shooter | ← → to move, Space/Z to shoot | ◀ ▶ touch buttons + 🔥 |
| Asteroid Dodge | ← → ↑ ↓ or WASD | All 4 directional buttons |
| Snake | Arrow keys / WASD | All 4 directional buttons |
| Brick Breaker | ← → to move, Space to launch, mouse to aim | ◀ ▶ buttons + mouse drag |
| Flappy Style | Space or ↑ to flap | Tap screen or 🔥 button |
| Racing | ← → or A D | ◀ ▶ buttons |
| Target Master | Click/tap targets | Tap directly on canvas |
| Bubble Shooter | Aim with mouse, click to shoot | ◀ ▶ to aim, 🔥 to shoot |
| Memory Match | Click cards | Tap cards |
| Quick Reflex | Click when green | Tap when green |
